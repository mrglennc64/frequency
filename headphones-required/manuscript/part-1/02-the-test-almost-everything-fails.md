# Ch. 2 — The Test Almost Everything Fails
*Part I — The Problem · Target: 5 pp · Written STANDALONE-FIRST as the lead magnet in Week 3 (Jul 20–26), back-ported to book format in Week 4 · Status: not started*

## Purpose & role in the argument
The shareable sting. A 10-minute experiment any reader can run on any "binaural" track they own: the mono-sum test. If summing left+right to mono leaves the sound unchanged, there are no differing carriers — the track physically cannot produce a binaural beat. Most tracks fail. This chapter is written first as the standalone lead-magnet PDF (see `../../lead-magnet/spec.md`) and V1 on YouTube; the book version adds cross-references.

## Key points to hit
- The test, step by step, with free tools (Audacity mono-sum; phone-speaker quick version) — a reader with zero technical background must succeed on the first try
- What each outcome means: unchanged in mono = no binaural construction; beat disappears in mono = real two-carrier build
- Why this single test invalidates the majority of the genre at the point of delivery
- Run it on a named honest example too (a track that passes) so the test reads as a measurement, not a hit job
- What the test *doesn't* prove (a track can pass and still be mislabeled — forward-reference Ch. 5 and Ch. 11 for the full audit)

## Reuse from existing assets
- Audit sample methodology paragraph — "the one rule most creators miss": the beat exists only as the difference between two carriers delivered to separate ears
- "528 Hz Abundance Meditation" finding: MONO file, L/R identical, no carrier difference, beat frequency: none — the canonical failure
